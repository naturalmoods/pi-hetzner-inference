# Security Policy

## Supported versions

Only the latest published version receives security fixes. Upgrade before reporting a problem that is already fixed in a newer release.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use [GitHub private vulnerability reporting](https://github.com/naturalmoods/pi-hetzner-inference/security/advisories/new) and include:

- the affected version and environment;
- reproduction steps or a proof of concept;
- expected and actual impact;
- any suggested mitigation.

You should receive an initial response within seven days. Please allow time for a fix and coordinated disclosure before publishing details.
